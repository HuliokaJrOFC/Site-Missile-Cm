2.1 Conceito do Jogo Original

Missile Command · Atari 2600

Do que se trata?

Uma guerra nuclear pós-apocalíptica.

Ideia principal

Simulação de uma guerra nuclear apocalíptica, inspirada diretamente no medo e nas tensões da Guerra Fria na década de 1980. O jogador defende suas cidades interceptando mísseis inimigos antes que atinjam o solo.

5.3 Mecânicas e Fluxo · O Gameplay

Ações · Objetivo · Desafios

Ações

O jogador mira com o mouse e clica para disparar interceptadores contra os mísseis que descem do céu.

Objetivo

Proteger as bases pelo maior tempo possível, somando pontos a cada míssil destruído e buscando bater recordes.

Desafios

Ondas de mísseis cada vez mais rápidas e numerosas, munição limitada e bases que podem ser destruídas.

6. Explicação de uma parte do Código

Lógica do script · Destruição da cidade
// Exemplo: Script da Cidade no Unity
public class Cidade : MonoBehaviour
{
    private Animator animator;

    void Awake()
    {
        animator = GetComponent<Animator>();
    }

    public void Destruir()
    {
        animator.SetTrigger("Destruir");
    }
}

Função

Destruir() – aciona a animação de destruição da cidade.

Variáveis

animator – controla os estados da cidade no Animator do Unity.

Resultado

A cidade passa de intacta para flash e escombros (6 frames, 6 FPS) quando é atingida.
